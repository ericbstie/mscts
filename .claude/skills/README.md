Skills in this directory are Matt Pocock's agent skills for Claude Code, copied from
https://github.com/mattpocock/skills (`skills/engineering` and `skills/productivity`), MIT licensed.

Claude Code auto-discovers any `.claude/skills/<name>/SKILL.md` in this repo, so these are
usable immediately via their slash-command names (e.g. `/tdd`, `/code-review`, `/domain-modeling`,
`/grill-me`, `/handoff`).

To pull updates, re-copy the `skills/engineering/*` and `skills/productivity/*` directories from
the upstream repo.
